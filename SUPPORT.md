# Support

## Start here

- Read the English or Chinese README for installation and usage.
- Search existing issues before creating a new one.
- Use the prompt-case form for a new catalog entry, the bug form for reproducible failures, and the feature form for scoped improvements.

## What maintainers can help with

- Catalog structure, taxonomy, schemas, and validation failures.
- Website browsing, generated previews, and catalog generation.
- Template selection, required fields, and agent-ready data formats.
- Reproducible issues in the included `img2prompt` and catalog skills.

## What is outside project support

- Billing, availability, or account issues for image-model providers.
- Guaranteed output parity across model versions.
- Private prompt consulting, production art direction, or custom model training.
- Recovery of API keys, private images, or data submitted to another service.

For security-sensitive reports, follow `SECURITY.md` instead of opening a public issue.

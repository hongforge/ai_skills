# 工业模板系统

本库的模板不是“风格词集合”，而是可由创作者和 Agent 执行的视觉交付规格。它们只吸收行业通用的分类、结构化输入与避错思路；每个模板均以本项目的分类、生产协议和质量门槛重新设计。

## 模板契约

每套模板都包含六个层次：

1. **可替换变量**：把抽象任务变成可验证的输入；缺失值必须确认，不能由模型编造。
2. **需求解析协议**：先锁定受众、交付类型、画幅、焦点、信息密度和参考图保留项，再选择视觉风格。
3. **输出契约**：明确交付一张成品、一个流程板或一个规范板，避免输出情绪板和无关变体。
4. **制作结构**：以五维分类提供版式、保真、空间、光影或一致性要求。
5. **质量门槛**：先检查缩略图层级，再检查文字、事实、几何、材质与品牌风险。
6. **风险控制**：列出不可接受的失败模式，例如虚构数据、产品变形、人物换脸和参考图漂移。

## 30 套模板

| 模块 | 模板方向 |
| --- | --- |
| UI 与产品 | 产品落地页、数据看板、移动端关键任务流、运营数据表工作台 |
| 信息表达 | 说明型信息图、教学知识图解、决策路径信息图、创业路演图表 |
| 海报与内容 | 活动主视觉、字体主导海报、杂志封面、社媒轮播、报告封面 |
| 商品与研发 | 商品英雄图、详情页、商品对比说明、包装概念、产品研发拆解板 |
| 品牌与空间 | 品牌识别套件、品牌视觉规范板、室内空间提案、空间材质与动线体验板 |
| 人物与叙事 | 编辑人像、人物特写艺术指导、角色三视图、分镜叙事、插画风格帧 |
| 编辑与对比 | 图像编辑执行单、参考图保真编辑协议、视觉方向对比板 |

## Agent 选择流程

1. 先根据成品类型、工作流、能力重点和模型检索案例。
2. 选择与案例交付类型一致的模板，再填入经过确认的变量值。
3. 图像编辑任务必须同时提供源图、编辑区域、身份锚点和保留项。
4. 生成后按 `execution.review_order` 检查，无法验证的事实和精确文字应转交给人工设计工具处理。

生成后的 `data/prompt-library.json` 将 `execution` 同模板一并导出，使 Agent 可以读取输入政策、生产顺序、审查顺序和案例配对规则。

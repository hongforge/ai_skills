## Prompt

Create a photorealistic professional avatar of {{subject_description}}. Use a head-and-shoulders crop with the face centered, both eyes sharply focused, and a calm {{expression}}. Dress the subject in {{wardrobe}} against a clean {{backdrop_color}} studio background.

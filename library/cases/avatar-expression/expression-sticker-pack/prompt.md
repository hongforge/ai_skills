# 统一表情包

## Prompt

Create a clean 3-by-3 expression sticker sheet for {{character_description}}. Every tile uses the same head-and-shoulders crop, {{wardrobe}}, hairstyle, face proportions, camera angle, soft lighting, and {{background_color}} background. Vary only the nine requested {{expressions}}. Use {{visual_style}} with readable eyes, clear mouth shapes, generous margins around each head, thin consistent separators, and no visual clutter. Each expression must remain recognizable at small size. No full body, no pose changes, no extra characters, no text labels, no speech bubbles, no logo, no watermark.

## 使用说明

适合聊天贴纸、直播互动和社群表情资产；建议按“开心、惊讶、无奈、生气、害羞、思考、疲惫、得意、疑惑”填写情绪。

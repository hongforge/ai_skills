# AIGC 奥术法师角色卡

## Prompt

Create one vertical character-card illustration for an original {{character_class}}. Use {{face_anchors}} to lock a clear, expressive face and make {{magic_focus}} the single memorable magic anchor. Build {{costume_layers}} with believable fabrics, clasps, ornaments, and movement logic; keep hands anatomically correct and the spell effect readable without obscuring the face. Use {{scene_palette}} for the atmospheric setting, magical glow, and controlled accent color. Frame as a polished head-and-torso or three-quarter portrait with intentional negative space for a card title. No generic wizard collage, no extra characters, no existing IP, no readable text, no logo, no watermark.

## 使用说明

适合法师、治疗者、召唤师等角色的设定卡。系列中应锁定法术符号、光色、配饰材质与人脸锚点，再只变化职业和场景。

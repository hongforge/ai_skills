# AIGC 游戏 Boss 场景

## Prompt

Create a cinematic original game boss-arena keyframe. Show {{boss_description}} confronting {{player_character}} in {{arena}} as {{attack_cue}} begins. Establish scale through a readable player silhouette, foreground debris or terrain, a clearly usable combat floor, and one environment mechanism that explains the arena. Use {{lighting}} with coherent shadow direction, controlled effects, and strong focal separation between boss, player, and threat. The scene should feel playable and physically structured, not like an abstract explosion. No gore, no existing game IP, no HUD, no readable text, no logo, no watermark.

## 使用说明

适合动作、RPG 和冒险类游戏的战斗推广图；需要给出 Boss 的攻击提示和场地机制，才能避免普通怪兽站桩图。

# AIGC 动漫世界观场景

## Prompt

Create an original anime world-building scene based on {{world_concept}}. Place {{protagonist}} in {{location}} with {{story_clue}} visible as one meaningful foreground or midground detail. Build a coherent environment through foreground texture, readable architecture or terrain, atmospheric distance, and human scale; the setting must explain the world without a caption. Render in {{visual_style}} with a controlled palette, physical light direction, and a clear focal route from protagonist to clue. No copied franchise imagery, no unrelated crowd, no text, no logo, no watermark.

## 使用说明

适合世界观发布、剧情章节页与动画背景概念；世界观概念应写清科技/魔法规则、时代和核心环境材料。

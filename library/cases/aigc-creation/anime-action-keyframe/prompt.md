# AIGC 动漫动作关键帧

## Prompt

Create one original anime action keyframe of {{protagonist}} performing {{action}} against {{opponent_or_obstacle}} in {{location}}. Use a decisive camera angle, one readable action line, controlled foreshortening, and a clear sequence of cause, motion, and impact. Keep the protagonist's face, costume anchors, and signature props consistent; use {{palette}} to distinguish character, threat, and environment without turning the image into effect noise. Render a single polished keyframe, not a storyboard sheet. No graphic gore, no existing IP, no text, no logo, no watermark.

## 使用说明

适合动画 PV、漫剧高潮和游戏联动视觉；动作应具有明确起点、方向和目标，避免无意义的特效堆叠。

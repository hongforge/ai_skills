# 漫剧开场钩子关键帧

## Prompt

Create one vertical 9:16 comic-drama opening keyframe. {{protagonist}} is caught by {{threat}} in {{setting}}. Use a single readable reaction, a clear physical trigger, and one unanswered visual clue so the conflict is understood before any dialogue. Frame the protagonist in the foreground or near foreground, reserve the upper third for optional editorial title treatment, and let the threat remain legible without filling the image with action effects. Use {{visual_style}} with {{palette}}, stable costume anchors, cinematic directional lighting, clean silhouette separation, and depth that leads directly to the protagonist's eyes. No full storyboard grid, no speech bubbles, no platform interface, no celebrity likeness, no text, no logo, no watermark.

## 使用说明

适合第一集开场、章节封面和投流首图；威胁应是可视的剧情触发，而不是抽象氛围词。

# Security Policy

This repository primarily contains documentation, structured prompt data, and
validation tooling.

## Supported versions

Security fixes are applied to the latest version on the default branch. Older
tags and forks are not maintained by this project.

## Reporting

If you discover a security issue in the tooling, dependency chain, generated
site, or CI configuration, use GitHub's private security advisory feature.
Do not open a public issue before a fix is available.

Do not include API keys, private images, personal data, or exploit details in
public reports. Include a minimal reproduction, affected files, expected
impact, and any suggested mitigation. Maintainers will acknowledge valid
reports, assess severity, and coordinate a fix before disclosure.

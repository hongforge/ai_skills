# Changelog

- 123 structured AI image prompt cases across the project taxonomy.
- 30 production-oriented prompt templates with required fields, quality gates, and risk controls.
- Generated preview covers, searchable Vite gallery, and card-level detail dialogs.
- Machine-readable catalog data and an agent-ready prompt-library Skill.
- Image-to-prompt Skill with model-neutral analysis and multiple model dialects.
- Validation tests for cases, templates, generated data, and Skill structure.
